Privacy Policy

Last updated: November 22, 2026

Web CO₂ Report Card is a browser extension that estimates the carbon emissions of the web pages you load. It is built to work entirely on your device.

What the extension reads

  • The size of each network request a page makes, read from the browser's request events (webRequest) and Performance API. The extension sees each request's address while measuring it but does not store or transmit it.
  • The domain name of the site you're on (for example, example.com), used to grade the page and show which sites account for the most emissions.

When you open a "Why this grade?" report, the extension reads the list of files on that page (their addresses, sizes, types, and response headers such as compression) and the pixel dimensions of its images, so it can explain the page's grade. This detail is kept in memory for the open tab only, cleared when the tab navigates or closes, and never stored or sent anywhere.

The extension does not store full URLs and does not read page content, form inputs, passwords, cookies, or any personal information.

Where data is stored

All data is stored locally in your browser's extension storage (chrome.storage.local) on your device. It includes running totals, a per-domain total, a page count, the date tracking started, and your display settings. Byte counts for open tabs are held in temporary session storage and cleared when the browser closes.

What is shared

Nothing. The extension makes no network requests and sends no data to the developer or any third party. There are no accounts, analytics, advertising, or tracking. Data is never sold or transferred.

Consent

Tracking is off when the extension is installed. Nothing is recorded until you read the disclosure and choose Start tracking.

Deleting your data

Click Reset Counter in the extension popup to erase all emissions data. Removing the extension deletes everything it stored.

Changes

If this policy or the extension's data practices change, the change will be described here and shown in the extension before it takes effect.
