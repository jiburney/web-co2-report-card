What it does

🅰️

A grade for every site

The toolbar badge shows each site's grade from A+ to F. It's based on the median weight of the last 20 pages you loaded there, so one unusual page doesn't swing it.

🔍

Why this grade?

Open a report for any page to see where its weight comes from, its heaviest files, and specific fixes: oversized images, older image formats, uncompressed files, and third-party weight. Each fix shows an estimated saving and the grade the page would get.

📅

Your week, by site

See the sites you visited grouped by grade, how many grade C or better compared with last week, and a 7-day chart of your browsing's CO₂.

📡

Measures everything

Counts every file a page loads, including ads, embedded frames, and video that loads after the page appears. Pages served from cache still get a fair grade.

🌍

Established methods

CO₂ estimates use the Sustainable Web Design Model v4 via CO2.js from the Green Web Foundation. Everyday comparisons use U.S. EPA factors.

🪶

Light to run

The extension makes no network requests of its own. In testing, handling each request a page made took about 5 microseconds. Report details are gathered only when you open a report.

How grades work

Grades follow the Digital Carbon Ratings from the Sustainable Web Design project. The cutoffs come from the sizes of real web pages in the HTTP Archive (June 2023). The scale is strict on purpose: the median web page earns an F.

How it works

1

Install and turn it on

A welcome page explains what the extension reads. Nothing is recorded until you click Start tracking.

2

Browse normally

Each site's grade appears on the toolbar icon once its first page finishes loading.

3

See why

Open the popup and click Why this grade? for a breakdown of the page and what would improve it.

4

Watch your week

The popup shows how the sites you visit break down by grade, compared with the week before.

🔒

Everything stays on your device

The extension stores byte counts and domain names in your browser and makes no network requests. There are no accounts, analytics, or ads. Full page addresses are never saved, and report details are cleared when you close the tab. Read the privacy policy.

Install it manually:

  1. Download the ZIP file and extract it to a folder.
  2. Open chrome://extensions (or edge://extensions, brave://extensions).
  3. Turn on Developer mode in the top right.
  4. Click Load unpacked and select the extracted folder.
  5. Click Start tracking on the welcome page, then reload any tabs that were already open.
