## How to Use This Template

### Google Forms
1. Go to [forms.google.com](https://forms.google.com)
2. Create new form titled "Carbon Footprint Tracker - Beta Feedback"
3. Add description: "Thanks for testing! Your feedback helps make this better."
4. Copy each question above
5. Set appropriate question types (multiple choice, scale, paragraph, etc.)
6. Mark optional questions as "not required"
7. Enable "Collect email addresses" (Settings) if you want to follow up
8. Share the form link with beta testers

### TypeForm (Alternative)
- More polished UI
- Better mobile experience
- Free tier: 10 questions, 10 responses/month
- Paid tier: Unlimited

### Microsoft Forms (Alternative)
- Good for enterprise users
- Integrates with Microsoft 365
- Similar features to Google Forms

## Sharing the Form

Include the form link in:
- Your beta distribution email
- The BETA-TESTING.md file
- A reminder email after 3-5 days
- Follow-up after they've used it for a week

- Tester name

- Key feedback themes
- Bugs reported
- Follow-up needed?

## Key Metrics to Track Manually

From responses, calculate:
- **Response rate**: % of testers who filled it out
- **Average ratings**: Clarity, usefulness (Q6, Q7)
- **Net Promoter Score**: % "Yes definitely" minus % "No definitely" (Q8)
- **Feature rankings**: Which features are most/least valued
- **Bug frequency**: How many testers hit each issue
- **Retention intent**: Average of Q18

## When to Send

**Timing options:**
1. **Immediate**: Include form link in first beta email (low completion rate)
2. **After 3 days**: Give them time to use it (better feedback quality)
3. **After 1 week**: Most complete usage picture (might forget details)
4. **Both**: Quick initial survey after 2 days + detailed survey after 1 week

**Recommended:** Send after 3-5 days of usage for best balance.
