Carbon Footprint Tracker

Grade each page you visit and see an estimate of the CO₂ your browsing produces.

What this extension reads

  • The size of each network request a page makes, including ads and embedded content. The extension sees each request's address only long enough to measure it and keeps the size.
  • The domain name of the site you're on (for example, youtube.com), so it can grade the page and show your top sites.
  • When you open a "Why this grade?" report, the files on that page (their addresses, sizes, and types) and the size of its images. This is used for the report only and is not saved.

Where it goes

  • Everything is stored on this device in your browser's extension storage.
  • Nothing is sent to any server. There are no accounts, analytics, or ads.
  • Full URLs, page content, and form data are never read.
  • You can erase all data at any time with Reset Counter, or by removing the extension.

Nothing is recorded until you click Start tracking.

You're set

Tracking is on. Pin the extension so the running total stays visible: click the puzzle-piece icon in Chrome's toolbar, then the pin next to Carbon Footprint Tracker.
