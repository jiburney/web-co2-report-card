📥 Installation Instructions

For Chrome / Edge / Brave

  1. Download the extension
    Download and save the ZIP file, then extract/unzip it to a folder on your computer
  2. Open Extensions Page
    • Chrome: Type chrome://extensions/ in the address bar
    • Edge: Type edge://extensions/
    • Brave: Type brave://extensions/
  3. Enable Developer Mode
    Look for "Developer mode" toggle in the top right corner and turn it ON
  4. Load the Extension
    Click "Load unpacked" button (top left), select the dist folder inside the extracted folder, then click "Select Folder"
  5. Done!
    You should see "Carbon Footprint Tracker" in your extensions list and the icon in your toolbar

For Firefox

  1. Download and extract the ZIP file
  2. Type about:debugging#/runtime/this-firefox in the address bar
  3. Click "Load Temporary Add-on..."
  4. Navigate to the dist folder and select any file (like manifest.json)
  5. Click "Open"
Note: In Firefox, the extension will be removed when you close the browser. This is normal for temporary add-ons.

✅ What to Test

1. Basic Functionality

  • Visit several websites (YouTube, GitHub, Reddit, etc.)
  • Click the extension icon - counter should increase
  • Visit more sites - counter continues to grow
  • Close and reopen browser - counter persists

2. Badge Colors

  • Icon badge starts Green
  • After ~10 pages, badge turns Yellow
  • Keep browsing - badge progresses: Orange → Red → Purple
  • Open popup - intensity indicator matches badge color

3. Contextual Comparisons

  • Open popup - see comparison (e.g., "📱 Like charging a smartphone")
  • Keep browsing - comparison updates appropriately
  • Different totals show different comparisons

4. Top Sites

  • Visit various sites multiple times
  • Open popup - see "Top Sites" section
  • Sites ranked by emissions
  • Percentages shown for each site

5. Reset Function

  • Click "Reset Counter" button
  • Confirm the dialog
  • Counter resets to 0.0 g
  • Badge returns to green
  • Top sites list clears

🔍 What to Look For

Bugs 🐛

  • Does anything crash or throw errors?
  • Any visual glitches or display issues?
  • Does the counter ever go backwards?
  • Do the colors look wrong?

Performance 💨

  • Does browsing feel slower?
  • Does your computer fan spin up?
  • Are pages loading normally?
  • Any noticeable lag when opening the popup?

Accuracy 🎯

  • Do the emissions numbers seem reasonable?
  • Are heavy sites (YouTube, image galleries) ranked higher?
  • Does the badge color reflect your browsing intensity?

User Experience 🎨

  • Is the UI clear and understandable?
  • Are the comparisons helpful?
  • Is any information confusing?
  • What would you change?

🔒 Privacy Note

All your data stays completely local on your device.

We don't collect any analytics, telemetry, or browsing data. The extension never makes external network requests. Your privacy is 100% protected.

⚠️ Known Limitations

  • Firefox users: Extension is temporary and will be removed on browser restart
  • Developer Mode Warning: Chrome will show a banner about "extensions in developer mode"
  • No auto-updates: When a new version is released, you'll need to reinstall manually

🔄 Getting Updates

When a new beta version is available:

  1. Delete the old extracted folder
  2. Download the new ZIP
  3. Extract it
  4. Go to chrome://extensions/
  5. Click the reload icon (↻) on Carbon Footprint Tracker
    OR remove the old one and load the new folder
